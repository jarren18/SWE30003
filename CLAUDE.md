## Writing conventions (all deliverables)
- British/Australian spelling (organise, behaviour), plain English and the active voice.
- Harvard referencing, matching the A1 reference list.
- Number every section and every figure and table caption. Each cross-reference ("Section N", "Figure N", "Task N") must resolve to something that exists. A1 lost marks for stale task numbers.
- Use Mermaid for diagrams, with a legend for the notation.
- Use one term per concept, and use A1's domain names (Tourist, Local Service Provider, Management Staff, Booking, Accommodation, Vehicle, Food Establishment) unless a decision record renames them.

## Assignment 2 hard rules (from the rubric)
- The class diagram shows no attributes, methods or signatures (up to −5).
- Every class in the diagram has a CRC card (−4 per missing card). Each card has a superclass, a description, and responsibilities with collaborators listed per responsibility (−1 per missing item).
- The bootstrap uses only defined classes (−1 per undefined class).
- Verification has at least 4 non-trivial scenarios, each shown as a sequence diagram.
- The A1 PDF is attached as an appendix, and the signed cover sheet and contribution worksheet are included.
- `check_ood.py` enforces these mechanically. A hook runs it whenever `FINAL_OOD.md` changes.
