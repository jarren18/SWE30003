# Assignment Expectations: Initial Object-Oriented Design

Based on the provided case study (from Assignment 1), you are expected to develop an initial object-oriented design. Specifically, the following information must be provided:

## 1. Core Design Deliverables

* **Overview of Candidate Classes:** 
  * Provide a list of classes that define your solution.
  * Include a graphical representation of their inter-relationships (e.g., a basic UML class diagram) following the Responsibility-Driven Design approach.
  * **Constraint:** Do *not* include any method names, signatures, or attributes/fields, as this is premature for the initial design stage. 
  * Provide a brief justification for your design choices.
  * *Note on Data Structures:* If your design contains record or struct-like abstractions, define them as data-holder classes and include them in the diagram. Acknowledge that these are treated as "data structure definitions" rather than standard classes.
* **CRC Cards:**
  * Create a CRC card for each identified class.
  * Include a brief description of the class and all its responsibilities.
  * Explicitly list all required collaborators *on a per-responsibility basis*.
* **Design Patterns & Heuristics:**
  * Illustrate any Design Patterns or Design Heuristics applied in the initial design.
  * Include a brief justification for their utilization.
* **Bootstrap Process:**
  * Illustrate the system's initialization sequence.
  * Detail which classes are responsible for instantiating other classes and the specific order of this execution.
* **Design Verification:**
  * Illustrate four typical, non-trivial interaction patterns/scenarios to verify your design (e.g., tracking how the system determines user input validity and applies it to a specific business process).

## 2. Document Structure & Administrative Requirements

Wrap all the deliverables in a coherent document structure that explicitly contains:
* Authorship details
* Document overview
* Any assumptions made during the design process
* External references utilized
* **Appendix Requirement:** Attach your Assignment 1 submission as an appendix in a separate PDF.
